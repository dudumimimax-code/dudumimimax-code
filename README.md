## 🚀 Projetos em destaque

### 🦂 Escorpiões em Cotia: Pipeline de Dados (SINAN × INMET)
Pipeline de engenharia de dados que trata as notificações de acidentes por escorpião da região de Cotia e as cruza com o clima diário, em camadas Bronze → Silver → Gold.

- Mais de 7 mil casos de 2016 a 2026, decodificados e cruzados com chuva, temperatura e umidade por **SQL no DuckDB** (99,9% dos casos com clima).
- Leitura do SINAN otimizada: de mais de 10 minutos para cerca de **36 segundos**, filtrando os bytes do arquivo antes de decodificar.
- Pipeline do INMET robusto a layouts diferentes entre os anos, com regras de limpeza e dicionários de dados documentados.
- 🔗 [Repositório](https://github.com/dudumimimax-code/escorpioes-cotia-pipeline)

### 🔍 Fraud Detection: Monitor de Transações de Cartão
Modelo de machine learning que classifica transações como fraudulentas ou legítimas, com um dashboard interativo para acompanhar os resultados.

- Random Forest treinado em **523 mil transações**, com validação fora do tempo (treino de janeiro a novembro, teste em dezembro).
- Base muito desbalanceada (apenas 3,9% de fraudes), avaliada com precisão, recall e PR-AUC em vez de acurácia.
- Resultado no mês de teste: **recall de 70%**, **precisão de 53%** e **PR-AUC de 0,61**.
- 🔗 [Dashboard ao vivo](https://dudumimimax-code.github.io/Fraud-Detetion/) · [Repositório](https://github.com/dudumimimax-code/Fraud-Detetion)
